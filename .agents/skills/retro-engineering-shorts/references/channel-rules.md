# Stage-specific channel rules

## Shorts: two visual videos (updated 13 October 2026)

For a Shorts request, read [retro-engineering-shorts](../SKILL.md) and settings.shorts. Default: two standalone Shorts, each with its own visual hook and complete answer; test duration 20–30 seconds, targeting about 25, 9:16, 1080×1920. “Living Mechanics” style: real prominent components, movement from the first frame, and a clear action/result sequence. Each shot defaults to 2–3 seconds from effective_settings.shorts.shot_duration_range_seconds, overriding the long-episode range. Conflict or intrigue is visible and audible immediately, without preamble or prolonged pauses. Pay special attention to visual changes during seconds 5–15. The last phrase and shot transition into the opening on replay; the first viewing already provides a complete answer. Looping does not permit repeating source ranges inside the file. Check the join through two consecutive playbacks. Set format="shorts" in timeline. No added text, burned-in subtitles, or text logos. Narration is Ukrainian under the profile, and each video requires a separate synchronized SRT. Provide one vertical text-free cover per Short; apply lighting, depth, and object recognition from the shared cinematic reference while adapting composition to vertical framing. Videos and covers must communicate the visual story without language knowledge. Real-source and generation restrictions remain in effect.

Configuring the skill does not start Shorts production. A full long episode does not include them automatically: a request or scope.shorts is required; an explicit count overrides the default. Deliver two MP4s, two JPGs, two SRTs, and two metadata sets in the episode's language folder under general rules.

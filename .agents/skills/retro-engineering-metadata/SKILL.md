# Retro Engineering: metadata

Apply only to retro-engineering. Read AGENTS.md, the merged profile, current script, research, and episode scope.

Follow the [current packaging rules](<../../../Данные проекта/research/current_production_rules.md>). The public name is PASTWORKS: use it in descriptions and CTAs, retaining the internal name/ID for production.

The title emphasizes a mystery, unusual effect, or tradeoff; the object is clear, but the model name need not come first. Three alternatives vary the angle: oddity → operating question → cost of the solution/result. Example structures: “Why did ... need ...?”, “... instead of ...: how ...?”, “Why didn't ... become the standard solution?” Do not stamp one formula onto every topic.

The title, text-free thumbnail scene, and first 20 seconds promise an answer to one question. Packaging must not claim a failure, ban, or revival unsupported by research. Take model, year, power, speed, and quantity from verified sources for the correct variant. “First” requires a clear criterion; an appealing name does not establish energy-free continuous operation or a world record.

Format long-video descriptions under “Long-video description format — 12 October 2026” in the current packaging rules: question and brief summary → specific episode questions → viewer question and CTA → “Розділи:” with verified timestamps → three hashtags → required attribution. Do not replace this structure with one generic sentence or a source list. Take key-source links from research_notes.md; when amending a released episode whose inputs were cleaned up, use retained source records and final synchronized subtitles, explicitly noting that the working script is unavailable. Tags cover the object, model, mechanism, and engineering field. Localize the intrigue naturally into every requested language while preserving technical meaning and names. Take counts and limits from the profile and explicit request. Check description length separately from titles and tags: at most 5000 characters including sources, attribution, and links. When covers change, update sources and the description to reflect actual materials, preserving authors, licenses, and modification details. A new delivered image does not change the YouTube thumbnail without a separate publishing request.

General format and mechanics: [retro-engineering-metadata](references/technical-workflow.md). Save all working results in Производство/episodes/<selected-episode>; do not use Bible-channel topics, sources, or assignments. Follow the current request for languages and file counts.

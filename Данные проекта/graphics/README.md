# Графические компоненты канала

Четыре редактируемых SVG-макета 1920×1080: карточка человека, ключевая сумма, поток денег, хронология. Это исходные графические компоненты, не готовые видеоклипы и не подтверждение работоспособности анимационного рендера.

Данные в {{...}} — незаполненные поля, не факты. Подставлять сведения из проверенных claims.json и people.json; учитывать длину подписей, разбиение строк и реальные размеры портрета. Портрет не встроен: сначала подтвердить личность и основание использования. data-animate указывает будущему рендеру задачу раскрытия, сам по себе SVG не создаёт анимированное видео.

Цвета и размеры — graphics.design_tokens в settings.json. Бирюзовый — основной акцент, янтарный — оговорки/неопределённость, красный — смысловой риск. Статус связи обозначать словами, не только цветом. При наложении на видео допускается прозрачный фон; читаемость и контраст проверить на реальном кадре и телефоне.

Перед экспортом: заполнить поля, проверить источники, отрендерить выбранным доступным инструментом, посмотреть движение, убедиться в читаемости. Не включать в фильм незаполненный макет или выдавать плоский SVG за готовую motion-графику.

# Человек без лица

Самостоятельный шаблон документального канала: даркнет, мошенничество, цифровые преступления, деньги и реальные личности.

[Скачать чистый архив шаблона](https://raw.githubusercontent.com/anzelina878-collab/v1/main/templates/faceless-channel-template.zip) — без старого фильма, озвучки и исторических сборщиков.

Начать с [руководства канала](<Данные проекта/channel-guide.md>), [визуального языка](<Данные проекта/visual-language.md>) и [settings.json](settings.json). Правила работы ассистента — [AGENTS.md](AGENTS.md).

Новый стиль: преимущественно движущийся сток и анимированная графика; реальные портреты и документы — по смыслу. Разрешены суммы, схемы, карты, даты, карточки людей и читаемые подписи. Меньше статичных картинок; выразительная анимация фотографий. Пайка и платы не заменяют рассказ о программах, деньгах и людях.

В .agents/skills/ — 11 новых навыков с префиксом faceless. Старые активные навыки заменены; история изменений сохранена в Git. [Контракт нового выпуска](<Данные проекта/production-contract.md>) отделяет редакторские требования от реально доступных инструментов.

Проверка шаблона:

```bash
python Производство/scripts/validate_template.py
python -m unittest discover -s Производство/tests -v
```

AI-видео не используется, отдельный видеогенератор не нужен. AI-фото — редкие вставки: цель около 5%, максимум 10% экранного времени с учётом повторов и наложений. Проезды сверху вниз, снизу вверх и в стороны, приближение и параллакс делают фото живее, но не исключают его из лимита. Старые инструменты выпуска 001 не поддерживают новый универсальный план и не должны выбираться для нового выпуска автоматически.

Изменение шаблона не пересобирает существующий ролик. История и озвучка пользователя сохраняются. Публикация, платные сервисы, музыка/SFX и Shorts определяются текущим заказом, а не историческими разрешениями другого профиля.

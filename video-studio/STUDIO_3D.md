# Предметная сцена и настоящая 3D-анимация

Новый тип `studio` дополняет существующий движок. Светлый фон, крупный предмет,
векторный флаг и название снизу слева. Старые демонстрационные шаблоны сохранены.

## Сцена

```json
{
  "id": "m4",
  "type": "studio",
  "duration": 7,
  "video": "assets/m4a1-turntable.mp4",
  "country": "US",
  "title": "M4A1",
  "motion_kind": "true_3d",
  "in": 0,
  "fit": "contain",
  "callouts": [{"start": 4.2, "end": 6.5, "text": "5,56 ММ"}]
}
```

Для проверенной фотографии: `image` вместо `video`, `motion_kind: verified_static`.
Запрещено обозначать фотографию как true_3d — валидатор отклоняет такую сцену.
В FFmpeg-компиляторе `camera_motion` управляет спокойным приближением к фото.
Это движение камеры над плоским материалом, не 3D. `full_bleed: true` используется
для документальной фотографии, а не изолированного предмета.

Флаги US и CN нарисованы геометрией, не emoji. `label_start` задерживает название,
а `callouts` выводятся только в заданных локальных интервалах. Данные и название
должны совпадать с фактически звучащей фразой.

## Blender

Нужен Blender 4.x с поддержкой используемого формата. Импортируются FBX, GLB,
GLTF, OBJ и объекты из BLEND. Запускайте с `--disable-autoexec`.

```bash
blender --background --disable-autoexec -t 3 --python tools/blender_turntable.py -- --model assets/model.glb --output output/model.mp4 --duration 6 --fps 30 --width 1920 --height 1080 --yaw-start -30 --yaw-end 30
```

`--texture-prefix` подключает атлас Base_Color / Metallic / Roughness / Normal.
`--model-rotation` задаёт три исходных угла в градусах. Рендер автоматически
нормализует размещение и проверяет габариты по диапазону поворота при подборе камеры.
Сохраняются BLEND, последовательность PNG и сведения `.3d.json`.

Cycles работает на CPU; Eevee требует исправного графического контекста. В текущей
среде Eevee недоступен, Cycles проверен, но медленный. Автопроверка `--self-test`
создаёт калибровочную геометрию, которая не используется в документальном выпуске.

## Быстрый CPU-рендер реальной сетки

```bash
python -m pip install -r requirements-3d.txt
blender --background --disable-autoexec --python tools/export_mesh.py -- assets/model.fbx assets/mesh.npz
python tools/software_turntable.py --mesh assets/mesh.npz --texture assets/model_Base_Color.png --output assets/turntable.mp4 --duration 10 --width 1920 --height 1080 --fps 30
```

Этот рендер поворачивает реальные вершины, проецирует треугольники с буфером глубины
и UV-текстурами. Это не перспективное искажение PNG. Освещение и мягкая тень
приближённые студийные, без физически точной трассировки лучей. Поддерживается
один атлас цвета на импортированный набор; для многоматериальных моделей нужен
Blender или предварительная корректная упаковка материалов.

Рендер **не подтверждает идентичность и лицензию модели**. Это отдельная проверка.
Нельзя подписывать близкую по внешнему виду модель чужим названием.

## Длинные выпуски

`render-fast` использует те же композиции Painter, но кодирует сцены через FFmpeg,
вводит подписи отдельными слоями и кеширует проверенные клипы. Текстовые схемы
имеют короткую анимированную последовательность, затем удержание последнего кадра.
Это не замена настоящего движения объекта. Кеш сбрасывается при изменении сцены,
файлов, шрифтов или рендера. Проект должен иметь полностью заданный таймлайн.

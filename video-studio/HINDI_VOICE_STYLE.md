# Hindi language preferences — ARSENAL 360 / शस्त्र 360

User instructions received 14 November 2026. Apply to future Hindi narration and newly prepared Hindi metadata. Do not modify already delivered films merely to apply these rules.

- Spell out the country as `संयुक्त राज्य अमेरिका` (Соединённые Штаты Америки), or use `अमेरिकी` (американский / американцы) where grammar allows. In English metadata use `United States of America` or an `American` adjective. In Russian translations use the full country name or американский / американцы. Do not shorten the country to initials in new titles, descriptions, tags or narration. Unchanged original input documents remain reference sources.
- For spoken decimal values, including calibres, follow the user's explicit convention: whole-number part + `और` + fractional part read as an integer + unit. Examples: five point fifty-six millimetres is written `पाँच और छप्पन मिलीमीटर`; six point eight millimetres is written `छह और आठ मिलीमीटर`. Do not use a decimal comma, decimal point or the word `दशमलव` in those narration phrases.
- This is a pronunciation convention, not a change to the underlying technical calibre. Preserve the original value in source records. Do not add a calibre which the original script does not give.
- Technical model names such as F-35, M7, HIMARS and THAAD remain model names. Keep a separate pronunciation guide for the voice provider.
- Use the Hindi brand `शस्त्र 360` in narration; the publication brand can include `ARSENAL 360 / शस्त्र 360`.
- Recalculate chapter times after the actual Hindi voice is provided.
- User feedback for future visual adaptations: do not pad archive clips by freezing their final frame. Cut to another relevant moving shot, an intentionally presented still or a suitable 3D view instead. This feedback does not authorize changes to already delivered video 1.

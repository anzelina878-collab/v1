# Предметно — студия видеоряда

**[Скачать готовый проект ZIP](https://github.com/anzelina878-collab/v1/raw/refs/heads/main/video-studio/output/video-studio.zip)** · [Посмотреть демо](output/demo.mp4) · [Начать здесь](START_HERE.md)

Переиспользуемый код для объясняющих видео: светлый фон, техническая сетка,
крупные предметы, короткие подписи, сравнения и диаграммы. Оформление вдохновлено
разобранным референсом, но не копирует его готовые материалы.

**Здесь создаём видеоряд. Текст и готовую озвучку предоставляет пользователь.**
Название «Предметно» — рабочее, его можно заменить полем `brand`.

## Что уже работает

- 9 типов сцен: intro, section, item, compare, bars, kit, diagram, footage, outro.
- Отдельная конфигурация для каждого выпуска; JSON редактируется без изменения шаблонов.
- Поэтапное появление подписей, анимация диаграмм, появление изображений.
- PNG с прозрачностью, JPG/WebP и другие изображения, читаемые Pillow.
- Видеовставки с начальной точкой, зацикливанием и заполнением/вписыванием кадра.
- Подключение готовой озвучки WAV/MP3/M4A через FFmpeg. Исходный звук видеовставок исключается.
- Проверка таймкодов, файлов, полей и длины медиа; читаемые ошибки при переполнении текста.
- Превью одного кадра и общая раскадровка; MP4 H.264 и AAC при наличии аудио.
- Шрифты с украинской кириллицей включены в проект.

Это шаблонный движок, а не модель, понимающая сценарий. Когда пользователь
присылает новый текст и озвучку, в Codex под них готовим сцены, изображения и
таймкоды. Сам JSON не превращает произвольную прозу в корректный видеоряд.
Внутри проекта нет API-ключей, платных сервисов и генерации голоса.

## Установка

Нужны **Python 3.10+** и **FFmpeg с ffprobe и libx264** в PATH.

```bash
python -m venv .venv
```

Активация macOS/Linux:

```bash
source .venv/bin/activate
```

Активация Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Затем:

```bash
python -m pip install -r requirements.txt
ffmpeg -version
ffprobe -version
```

FFmpeg ставится отдельно: например, `brew install ffmpeg` на macOS,
`sudo apt install ffmpeg` на Ubuntu или подходящий пакет FFmpeg в Windows.
Интернет нужен для установки, но не для рендера.

## Посмотреть демонстрацию

Готовые файлы находятся в `output/demo.mp4` и `output/storyboard.jpg`.
Демо длится 40 секунд, 960×540, 24 fps, без озвучки. Все предметы условные,
числа синтетические. Это демонстрация шаблонов, не законченный документальный выпуск.

Пересобрать:

```bash
python render.py validate episodes/demo/episode.json
python render.py preview episodes/demo/episode.json --output output/storyboard.jpg
python render.py preview episodes/demo/episode.json --at 9 --output output/frame.jpg
python render.py render episodes/demo/episode.json --output output/demo.mp4
```

Исходные демоизображения включены. При необходимости их можно повторно нарисовать:

```bash
python tools/build_demo_assets.py
```

## Новый выпуск

```bash
python render.py new episodes/002-example
```

Появятся `episode.json`, `INPUTS.md`, папки `assets`, `audio`, `output`.
Выпуски не перезаписываются. Входные пути в JSON отсчитываются **от папки JSON**,
а путь после `--output` — от текущей рабочей папки терминала.

Пользователь присылает:

1. Финальный текст для понимания содержания.
2. Готовый голосовой файл.
3. Референсы и обязательные изображения, если они есть.
4. Пожелания к длительности, стилю и разрешению.

В Codex готовим план визуальных сцен, материалы, тайминги и финальный рендер.
Новый сценарий не требует копирования кода рендера.

Пример подключения готовой озвучки:

```json
"audio": "audio/voice.wav",
"audio_policy": "strict"
```

В сцену предмета добавляем:

```json
"image": "assets/object.png"
```

После заполнения:

```bash
python render.py validate episodes/002-example/episode.json
python render.py timeline episodes/002-example/episode.json
python render.py preview episodes/002-example/episode.json --output episodes/002-example/output/storyboard.jpg
python render.py render episodes/002-example/episode.json --output episodes/002-example/output/final.mp4
```

Пока изображения ещё не готовы, `--allow-placeholders` разрешает видимые
заглушки. По умолчанию финальная сборка без нужных изображений не проходит.

## Синхронизация с голосом

Сцены имеют `duration` в секундах. `start` можно не писать: он вычисляется
последовательно. Если `start` указан, движок проверяет отсутствие разрывов и наложений.
Измените длительности по голосу, а не подгоняйте голос под произвольные карточки.

- `audio_policy: "strict"`: ошибка, если озвучка длиннее сцен более чем на один кадр.
- `audio_policy: "pad_video"`: при длинной озвучке удерживается последний кадр.
- Если голос короче видео, конец аудио заполняется тишиной.
- `audio: null`: MP4 без аудиодорожки.

Продление последнего кадра — страховка, не автоматическая синхронизация речи.
Отдельные паузы, смена объектов и акценты на конкретных словах задаются планом сцен.

## Стиль и ограничения

Базовый дизайн 1920×1080. Демо экспортируется в 960×540 ради скорости; новый
выпуск по умолчанию 1920×1080, 30 fps. Произвольные пропорции вписывают горизонтальный
дизайн с полями; отдельной вертикальной композиции пока нет.

Цвета и шрифты задаются через `theme`, поля описаны в FORMAT.md. Изображения нужно
предварительно подготовить: движок **не удаляет фон** и не генерирует рисунки по тексту.
Для лучшего результата используйте прозрачный PNG и согласованный ракурс.
Для точных моделей техники используйте проверенные изображения, а не случайный
результат генерации. Указывайте источники и используйте материалы с подходящими правами.

Здесь нет полноценных 3D-сцен, генерации видео, автоматической проверки фактов,
субтитров, монтажа музыки, сложных композитных переходов и автоматического выравнивания речи.
Схема `diagram` — последовательность блоков; более сложные объяснения добавляем
отдельными шаблонами по мере появления реальных задач.

Рендер идёт на CPU, последовательно, без хранения всех кадров в памяти. 16-минутный
выпуск в Full HD может рендериться заметно дольше реального времени. Сначала
проверяйте раскадровку и короткий фрагмент.

После рендера рядом с MP4 создаётся `.render.json`: параметры и тайминги сборки.
Код конфигурации не содержит имена секретов или внешние подключения.

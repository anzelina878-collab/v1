# АРСЕНАЛ 360° — заставка v1

Готовая заставка: `output/arsenal_360_intro_v1.mp4` — 6 секунд, 1920×1080, 30 кадров/с, H.264. Без звука: отдельный визуальный материал для монтажа.

Сотни окон мозаики показывают реальные движущиеся фрагменты 13 исходных видео с разными временными смещениями. Это не сотни независимых исходников. Название появляется диагональным световым прорезанием, затем удерживается до конца. Вся анимация воспроизводится локально, без платных API.

## Запуск

Установите Python 3.10+ и FFmpeg (команды ffmpeg/ffprobe должны быть доступны в PATH).

```sh
python -m pip install -r requirements.txt
python build_intro.py
```

Предпросмотр без кодирования MP4:

```sh
python build_intro.py --preview-only
```

В `intro.json` можно заменить название, seed раскладки, начало и конец появления текста. Для других выпусков заменяйте MP4 в `assets/`: минимум четыре источника длиной от восьми секунд. Отдельная папка проекта сохраняет предыдущую версию. Мастер рассчитан на 1920×1080, 6 секунд, 30 fps; изменение этих параметров требует изменения рендера. Новые названия должны помещаться в кадр; длинные строки уменьшаются автоматически.

`output/storyboard.jpg` — раскадровка. `output/logo_white.png` — белая надпись на прозрачном фоне. `output/render.json` — параметры, число окон и контрольная сумма видео. `assets/*.source.json` — происхождение каждого фрагмента. Все 13 коротких исходников входят в проект, повторное скачивание не требуется.

# Випуск 001 — США проти Китаю

Повний монтаж за наданою озвучкою. Основна конфігурація: episode.json.
Часові прив’язки з реальної аудіодоріжки: timeline.json.

Формат: 1920×1080, 30 fps, H.264/AAC. Аудіо — audio/voice.mp3; швидкість не змінена.

Важлива межа поточної версії: справжня 3D-геометрія використана для M4A1.
Решта предметів показані перевіреними фото з помірним рухом камери,
як дозволений у ТЗ fallback. Це не повністю тривимірний фільм.
Для QJS-161 використана типографічна схема, а не зображення іншого кулемета.

Архів output/project_source.zip містить код студії, підготовлені матеріали, модель M4A1,
оригінальну надану озвучку, текст, конфігурацію та реєстр джерел.
Оригінали фотографій збережені у виробничій бібліотеці; в архіві є підготовлені зображення та точні посилання на оригінали. Це прибирає дублювання без втрати можливості повторного рендера.
Тимчасові кеші, моделі розпізнавання та проміжні WAV не включаються.

Перезбірка з кореня video-studio:

```bash
python -m pip install -r requirements.txt
python render.py validate episodes/001-usa-china-2026/episode.json
python render.py render-fast episodes/001-usa-china-2026/episode.json --output episodes/001-usa-china-2026/output/final_video.mp4 --crf 22
```

Для зміни ракурсів 3D дивіться STUDIO_3D.md. Для нового випуску — START_HERE.md.
Автори, умови використання й зміни кожного зображення — SOURCES.md та assets_manifest.json.

# Revision 2 — круговое вращение

Запрос: сохранить понравившуюся светлую композицию, вращать все предметы как
3D-оружие, добавить анимацию заголовков и немного архивного видео.

## Что подготовлено

- Новые настоящие обороты M4A1 и M249: 360° / 12 секунд, 1920×1080, 30 fps.
- Появление заголовков и подписей; отключение повторного появления в продолжении
  одного предметного плана. Включается в конфиге `title_motion: true`.
- Две четырёхсекундные архивные вставки U.S. Army, с источником и без их звука.
- `review.v2.json` — отдельный 36-секундный монтаж для просмотра этих правок.
  Его озвучка — только фрагменты исходной пользовательской записи.
- `turntables.v2.json` — расширяемая библиотека готовых вращений и недостающих
  моделей. `tools/apply_turntables.py` применяет её к предметным сценам нового
  выпуска, проверяет наличие источников и отчёта реального 3D-рендера.

## Что ещё не выполнено

Все предметы полного выпуска пока не обеспечены точными 3D-моделями.
`episode.v2.draft.json` — частично подготовленный конфиг, не готовый полный
фильм. `.coverage.json` перечисляет оставшиеся предметные сцены и панели.
Сравнения, наборы и схема QJS-161 также требуют отдельной анимации после
подготовки моделей. Готовый просмотр не подтверждает завершение этих работ.

Для редких предметов нужна доступная проверенная геометрия с разрешённой
лицензией либо явное согласование иллюстративных реконструкций. Без такого
согласования фотографии не подменяются вымышленными «точными» 3D-моделями.

Версия 1, оригинальный текст и полный исходный звук сохранены.

## Запуск просмотра

Из папки `video-studio`, после установки `requirements.txt` и FFmpeg:

```bash
python render.py validate episodes/001-usa-china-2026/review.v2.json
python render.py render-fast episodes/001-usa-china-2026/review.v2.json \
  --output episodes/001-usa-china-2026/output/review_v2.mp4
```

См. `SOURCES_V2.md` для лицензий и исходных таймкодов, `STUDIO_3D.md` для
импорта моделей и подготовки следующих выпусков. Готовые ролики вращения
можно использовать без повторной установки Blender/DracoPy.

# Sources for revision 2

This revision keeps the user's supplied narration. `review_v2.mp4` is a 36-second
review montage of excerpts, not a completed replacement for the 17:43 film.

## Actual geometry

- **M4A1** — nisu, [OpenGameArt](https://opengameart.org/content/m4a1-assault-rifle),
  CC0. Existing licensed mesh, new 12-second / 360-degree render.
- **M249** — NoBE Aubé, [M249 SAW Machine gun](https://www.blendkit.com/asset-gallery-detail/6b3ab3d4-e6f7-4623-a808-0d84eccfda69/),
  [Blendkit Royalty Free license](https://www.blendkit.com/docs/licenses/).
  Creator describes the model as based on an M249 with tactical attachments.
  Selected as an editorial model of that weapon; not an engineering-certified
  factory reference. Full geometry and original base-color materials are used.
  CPU lighting approximates studio lighting; normal/metalness maps are not used
  by this renderer. No raw model or converted mesh is redistributed in this repo
  or the update archive; the rendered video is the distributable derivative.

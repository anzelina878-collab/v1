## Проект и повторная сборка

`project_source_v4.zip` содержит код, исходный голос, исходный текст/ТЗ,
проверенные изображения и готовые 3D-обороты. Подготовленные архивные видеовставки
загружаются отдельной командой по проверяемому манифесту (81 файл, около 234 MiB).
Они не дублируются внутри ZIP. Не требуется аккаунт, API-ключ или Git LFS на
компьютере пользователя: загрузчик работает по публичным HTTPS-ссылкам.

Из распакованной папки `video-studio`:

```bash
pip install -r requirements.txt
python tools/fetch_episode_media.py episodes/001-usa-china-2026/episode.v4.json
python render.py validate episodes/001-usa-china-2026/episode.v4.json
python render.py render-fast episodes/001-usa-china-2026/episode.v4.json \
  --output episodes/001-usa-china-2026/output/my_render_v4.mp4 --crf 23 --preset fast
```

Нужны Python и FFmpeg. Для пересборки с уже готовыми вращениями Blender не нужен.
Какие модели передать для остальных предметов — `WHAT_TO_SEND_FOR_3D.md`.
Источники архивов — `SOURCES_V4.md`; модельные лицензии — `SOURCES_V2.md`.

Для дальнейших правок можно применять `tools/prepare_archive.py` с локальной
библиотекой оригинальных видео. Быстрая сборка `tools/assemble_revision.py`
использует только проверенные кеши неизменённых планов; если кеша нет или
менялся движок/исходник, сначала используется обычный `render-fast`.

Вариант v3 и исходные материалы сохранены. Исходная Royalty Free геометрия M249
не распространяется; включён готовый разрешённый видеорендер.

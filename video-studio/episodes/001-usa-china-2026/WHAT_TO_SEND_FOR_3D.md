# Что передать для круговой 3D-анимации всех предметов

Дополнительный «код для 3D» присылать не нужно. В проекте уже есть импорт моделей,
освещение, камера, рендер полного оборота и подстановка в монтаж. Нужна сама
трёхмерная геометрия каждого предмета: фотография не содержит его обратную сторону.

Предпочтительно **GLB с текстурами внутри**. Также подходят GLTF + BIN + текстуры,
FBX, OBJ + MTL + текстуры, BLEND с упакованными текстурами. STL без материалов
даст геометрию, но потребует дополнительной работы над реалистичным видом.

Присылайте отдельный ZIP на предмет:

```
M17.zip
  model.glb
  source.txt   # название, автор, ссылка и условия использования
```

Если текстуры отдельно, сохраните их папку и исходные названия. Для передачи
через чат удобнее архив до 30 МБ на предмет: обычно достаточно текстур 1K–2K.
Не присылайте пароли, API-ключи или доступ к аккаунту магазина. Можно самостоятельно
скачать модель из своего аккаунта и прикрепить файл сюда.

## Уже готовы в этом выпуске

- M4A1: настоящая геометрия, 360° за 12 секунд.
- M249: настоящая геометрия, 360° за 12 секунд.

Их вращение сохранено в версии v4. Короткий монтажный план показывает часть оборота;
в последовательных планах угол продолжается. Полный круг не ускоряется в 2 секунды.

## Что ещё нужно для полного набора

- Стрелковое оружие: M7, M8 (современная версия из сценария, не HK XM8), QBZ-95,
  QBZ-191, M320, M250, QBB-95, QJS-161, M17, Beretta M9, QSZ-92, QSZ-193,
  M110A1, QBU-88, QBU-191.
- Оптика/ПНВ: M157, ENVG-B; китайские приборы — с подтверждённым названием или
  как честно обозначенный общий пример.
- Противотанковые средства: Javelin, Carl Gustaf, HJ-12.
- Снаряжение: IHPS, MSV, китайский шлем и бронежилет, IFAK, рюкзак,
  форма OCP и Xingkong, оба полевых рациона, Black Hornet.
- Боеприпасы, если их нужно показывать отдельно: именно соответствующие
  упоминаемым калибрам варианты, не случайный похожий патрон.

Обычный P320 не подписываем M17, M249 не подписываем M250, другой шлем — IHPS.
Модель в магазине может быть бесплатной, но требовать входа для скачивания;
платные модели без согласованного бюджета не покупались.

## Если готовой модели нет

Для авторской иллюстративной реконструкции нужны фотографии спереди, сзади,
слева, справа и сверху, ориентировочные размеры и согласование, что это
иллюстрация без гарантии заводской точности. По одному фото точную геометрию
всех невидимых поверхностей восстановить нельзя.

## Код уже в проекте

Пример настоящего полного оборота в Blender:

```bash
blender --background --disable-autoexec -t 3 \
  --python tools/blender_turntable.py -- \
  --model models_inbox/M17/model.glb \
  --output episodes/001-usa-china-2026/assets/m17-turntable.mp4 \
  --duration 12 --fps 30 --width 1920 --height 1080 \
  --yaw-start -45 --yaw-end 315 --engine BLENDER_EEVEE_NEXT
```

Нужна установка Blender и FFmpeg. Для CPU-конвертации GLB и рендера геометрии:
`pip install -r requirements-3d.txt`; см. `STUDIO_3D.md`.
Модели из ввода можно готовить и подключать по очереди, не пересобирая сюжет,
не переписывая текст и не создавая новую озвучку.

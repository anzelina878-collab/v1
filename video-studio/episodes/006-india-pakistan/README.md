# АРСЕНАЛ 360° — Індія проти Пакистану

Редагований візуальний проєкт випуску 006. Тривалість 23:30, Full HD 1920×1080, 30 кадрів/с. Оригінальний український сценарій і надана озвучка «сжатие 2.mp3» збережені без зміни слів або темпу.

## Відтворення з ZIP

Розпакуйте всю папку `video-studio`. Потрібні Python 3.11+, FFmpeg/FFprobe та залежності `requirements-visual.txt`. Із папки `video-studio/episodes/006-india-pakistan`:

```sh
pip install -r requirements-visual.txt
python build_episode.py
python render_episode.py --preview --work /tmp/arsenal-006-render
python render_episode.py --pilot 90 --work /tmp/arsenal-006-render --output output/pilot.mp4
python render_episode.py --work /tmp/arsenal-006-render --output output/final_video_v1.mp4
python verify_episode.py output/final_video_v1.mp4 --compiled /tmp/arsenal-006-render --output output/qa
python verify_motion.py /tmp/arsenal-006-render output/qa/motion-verification.json
```

Готові банки карт, моделей, фото, архіви, шрифти й оригінальна озвучка включені у ZIP. Для звичайного повторного рендера завантаження зовнішніх матеріалів і ASR не потрібні. Сам GitHub-каталог містить код і метадані; повні медіафайли — у ZIP.

## Візуальний стиль

Світлий фон, великі українські назви техніки, широкі нижні плашки з прапорами, розділові заголовки із золотою рискою та питання глядачам наприкінці. Фото нерухомі. Інформаційні картки з’являються один раз і завмирають; повторної анімації появи немає.

Rafale B, Mirage 2000-5, МиГ-29 та AH-64 показані зі справжньої геометрії. Обертання повільне: 360° за 24 секунди, 30 кадрів/с. Короткий план показує частину оберту. Підпис «родина» відділяє модель сімейства від точної національної модифікації/лівреї. Геометрія, UV-текстури, ліцензії та конвертація — в `assets/models`. Невдалі умовні танки не використані: там залишені реальні фото.

Карти — тривимірна сітка реальних висот із плавною камерою та рельєфом Гімалаїв. Вертикальний масштаб перебільшений у 20 разів для читабельності. На картах лише географічні назви; джерела та опис інструментів винесені у `SOURCES.md` й `assets/maps/SOURCES.md`. Спірні північні ділянки мають пунктирне позначення. Це географічний огляд, не реконструкція конкретного удару.

Архіви мають джерела, ліцензії, авторів і потрібні уточнення про навчання/рік/оператора. Відео не зациклюються й не заморожуються. Повернення до одного джерела — більш ніж через 60 секунд після завершення попередньої вставки; вихідні інтервали не повторюються. Подробиці та межі перевірки — `SOURCES.md`, `claims.json`, `quality_report.md`.

## Наступний випуск

Збережіть попередні випуски й створіть нову папку. Замініть сценарій та озвучку тільки в ній. Розбийте сценарій на абзаци `inputs/paragraphs.json`. Для розпізнавання нової озвучки встановіть `requirements-preparation.txt` і виконайте:

```sh
python tools/transcribe_audio.py --input audio/voiceover.mp3 --language uk --model small
python align_audio.py
```

ASR використовується тільки для монтажних міток. Це не новий голос. Оновіть фактичну тривалість у `align_audio.py`, явно зіставте абзаци з кадрами у `visual_map.py` і скоригуйте вступ/розбиття фраз у `build_episode.py`. Для нових матеріалів заповніть `assets/manifest.json`: файл, автор, ліцензія, джерело та точна ідентифікація техніки. У `SOURCE_WINDOWS` задайте перевірені інтервали; одного тематичного збігу недостатньо. Для нових країн замініть прапори й географічні дані карт. Потім — нова розкадровка, 90-секундний пілот, повний експорт та перевірка.

Для перерахунку моделей потрібні `numpy`, `numba`, Pillow; запуск `python tools/render_model_banks.py`. Для карт — ті самі залежності й `tools/map_banks.py --kind region --duration 24` (також `north`/`navy`, 18 секунд). Повторне створення сегментації вимагає rembg і окремого перегляду масок; скрипт не гарантує придатність кожної вирізки.

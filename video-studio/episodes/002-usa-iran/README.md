# Выпуск 002 — США проти ІРАНУ

Монтаж по оригинальному пользовательскому тексту и готовой украинской озвучке. Светлая предметная студия и типографика из выпуска 001; новый выпуск сохраняет предыдущие фильмы.

## Готовые материалы

`output/final_video_v1.mp4` — итоговый MP4 1920×1080, 30 fps, H.264/AAC. Длительность 23:17,47; исходная озвучка 23:17,448 сохранена без изменения темпа. Последние 0,019 с округлены до границы видеокадра.

`chapters.uk.txt` — главы для описания YouTube. `SOURCES.md` — авторство и лицензии. `editorial_notes.md` — ограничения идентификации и исходного текста. `output/verification.json` — результаты фактически выполненных проверок.

## Повторная сборка

Проект ZIP содержит корень `video-studio` с движком, шрифтами и папкой этого выпуска. Установите Python 3.10+, Pillow, numpy и FFmpeg с libx264. Команды выполняйте в корне `video-studio`:

```sh
python -m pip install Pillow numpy
python episodes/002-usa-iran/render_episode.py --preview
python episodes/002-usa-iran/render_episode.py
```

Для изменения монтажа редактируйте `visual_map.py`, затем:

```sh
python episodes/002-usa-iran/build_episode.py
python episodes/002-usa-iran/render_episode.py --preview
python episodes/002-usa-iran/render_episode.py
```

`episode.json` имеет отдельную схему `arsenal.semantic-edit.v1` и собирается через `render_episode.py`, использующий существующий `studio.visuals.Painter`. Его не нужно передавать старому `render.py render`: новый сборщик отдельно проверяет фактическое число кадров каждого видеофрагмента и не зацикливает архив.

`alignment/transcript.jsonl` — распознавание предоставленной дорожки, не новый сценарий. `alignment/paragraphs.json` — соответствие абзацев аудио. Для повторной сборки распознавание не требуется.

## Правки, учтённые в этом выпуске

- На архивных видео — флаг и источник. Привязанные к речи цитаты поверх каждого клипа не добавляются.
- Информационные карточки анимируются один раз и затем полностью неподвижны. В коде нет повторного запуска появления или зацикливания этих сцен.
- Повтор и продолжение одного видеоисточника проходят проверку: от конца предыдущего показа до нового должно пройти больше 60 секунд. Если интервал меньше, используется соответствующая фотография, а не маскирующий повтор с новой подписью.
- Вращения M1 Abrams и M4A1 используют настоящую геометрию и полный оборот 360°. Остальные предметы показаны проверенными фото и видео; фотографии не выдаются за 3D.
- Исходная озвучка не переписывается, не растягивается и не заменяется.

Временные рабочие пути `/tmp/arsenal-002` в служебных метаданных фиксируют место сборки; готовая конфигурация использует относительные пути внутри этого выпуска. Архив проекта включает все используемые медиа и не требует повторного скачивания DVIDS.

## Геометрия 360°

Исходная модель Abrams и нейтральная треугольная геометрия находятся в `assets/models/abrams/`. Проверенный M4A1 — в `assets/models/m4a1/`. Для нового оборота установите зависимости из `requirements-3d.txt` и используйте общий `tools/software_turntable.py`:

```sh
python tools/software_turntable.py --mesh episodes/002-usa-iran/assets/models/abrams/abrams.npz --texture episodes/002-usa-iran/assets/models/abrams/abrams-colors.npz --output episodes/002-usa-iran/assets/video/abrams-360-fixed.mp4 --duration 10 --fps 30 --width 1280 --height 720 --yaw-start -25 --yaw-end 335
```

Полный оборот занимает весь соответствующий план. Изменение длительности плана ретаймит геометрический оборот целиком, без повтора появления подписей. Идентичность и лицензия новой модели всегда проверяются отдельно: растеризатор их не подтверждает.

## Если проект получен через GitHub

Полный набор исходного аудио и архивных MP4 находится в `output/project_source_v1.zip`. Скачайте этот архив с Git LFS и распакуйте его в отдельную папку: внутри полностью готовый `video-studio`. В обычном просмотре репозитория медиа не дублируются отдельно; это уменьшает повторное хранение одних и тех же видеозаписей. ZIP самодостаточен для повторной сборки.

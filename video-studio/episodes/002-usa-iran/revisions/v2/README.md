# Редакция 2 — США проти ІРАНУ

Полная версия 1920×1080, 30 fps, 23:17.467. Исходная украинская озвучка сохранена без изменения темпа и текста.

Реальные фотографии и архивные видео объединены с 12 видами вращающейся геометрии: F-22, B-2, F-14, МиГ-29, AH-64, UH-60, CH-47, Abrams, M4A1 и тремя авторскими схематичными внешними моделями Ford/Ghadir/Shahed-136. Последние прямо подписаны как схематичные; это иллюстрации, не точные инженерные реплики. Фотографии с отделённым фоном остаются фотографиями и не выдаются за 3D.

В первые 90 секунд — 35 планов. В длинных 3D-планах выполняется один полный оборот, затем фиксируется ракурс. Информационные карточки появляются один раз и после этого неподвижны. Повтор одного архивного источника допускается только более чем через минуту после завершения предыдущего показа.

На архивных видео восстановлены названия техники и широкая нижняя плашка с флагом, как в первом фильме. Неуместные цитаты удалены. У фото Ghadir обрезан нижний край с логотипом сайта; оригинал сохранён, авторство Hamed Jafarnejad / Fars указано отдельно. Источники остаются в углу. Водяные знаки на архивных видео сохранены.

## Повторная сборка

Из каталога video-studio, после установки requirements.txt, numpy и FFmpeg:

```sh
python episodes/002-usa-iran/render_revision_v2.py --preview
python episodes/002-usa-iran/render_revision_v2.py --work /tmp/arsenal-v2-cache --output /tmp/final_video_v2.mp4
python episodes/002-usa-iran/verify_revision_v2.py /tmp/final_video_v2.mp4 --compiled /tmp/arsenal-v2-cache --output /tmp/arsenal-v2-check
python -m unittest discover -s episodes/002-usa-iran/tools -v
```

В ZIP включены исходная озвучка, текст, монтажный JSON, изображения, видео, готовые обороты, исходная геометрия, лицензии и код. Для повторного монтажа Blender не нужен: готовые 3D-обороты уже включены. Для новой геометрии предусмотрены инструменты в tools/model_sources_v2 и общий tools/software_turntable.py. Исходный renderer и конфигурация версии 1 сохранены, новая сборка использует episode.v2.json и assets/manifest.v2.json.

Проверка включает полный машинный декод, совпадение длительности и кадров, корреляцию озвучки, неподвижность карточек, интервал архивных повторов и просмотр контрольных кадров. Непрерывный ручной просмотр и прослушивание всего фильма не заявляются.

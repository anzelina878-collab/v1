# Редакция 4 — разделы и вопрос зрителю

Полное видео США против Ирана, украинская озвучка, 1920×1080, 30 fps, 23:17.467. Исходная речь и её темп сохранены.

Добавлены 10 заставок: авіація, танки та бронетехніка, ракетне озброєння, піхотне озброєння, артилерія, безпілотники, протиповітряна оборона, вертольоти, військово-морський флот, підсумок. Использован тот же section-шаблон Painter, что в первом фильме: светлый фон #F2F3F0, крупный тёмный заголовок, золотистая линия, короткое появление, затем неподвижное удержание. Заставки занимают существующие переходные фразы и не удлиняют фильм.

В конце показан вопрос из этой озвучки: «Яка категорія найцікавіша?» — авіація, ракети, безпілотники, флот. Затем слайд «Ваша думка?» предлагает написать, арсеналы каких стран сравнить дальше. Сохранена финальная заставка канала. Question/diagram и outro используют оформление первого фильма; размер четырёх вариантов адаптирован, чтобы слова не разрывались.

Однократное появление длится до 1.2 секунды; у вопроса с четырьмя вариантами — до 1.6 секунды. После этого всё неподвижно. Утверждённые неподвижные фото и медленные 3D-повороты сохранены: 360° за 24 секунды. Фрагменты обрезаются по кадрам из утверждённого монтажа v3; фаза поворота и анимации после заставки не запускается заново.

## Повторная сборка

Из каталога video-studio, установив FFmpeg, requirements.txt и numpy:

```sh
python episodes/002-usa-iran/build_revision_v4.py
python episodes/002-usa-iran/render_revision_v4.py --preview
python episodes/002-usa-iran/render_revision_v4.py --work /tmp/arsenal-v4-cache --output /tmp/final_video_v4.mp4
python episodes/002-usa-iran/verify_revision_v4.py /tmp/final_video_v4.mp4 --compiled /tmp/arsenal-v4-cache --output /tmp/arsenal-v4-check
```

Необязательные повторяемые параметры --reuse <каталог_кэша> позволяют использовать проверенные фрагменты v3/v2. Без внешнего кэша все исходные планы строятся самостоятельно из включённых материалов. В ZIP входят конфигурации v1–v4, движок и шрифты, оригинальная озвучка, текст, фото, архивные видео, готовые 3D-повороты, исходная геометрия и лицензии. Для монтажа Blender не нужен.

Актуальные главы: chapters.v4.uk.txt. Источники: revisions/v2/SOURCES.md и assets/manifest.v2.json. Техническая проверка, контрольные кадры и проверка неподвижности заголовков: output/revision_v4. Автоматическая проверка полного файла и просмотр контрольных кадров не выдаются за непрерывный ручной просмотр/прослушивание всего ролика.

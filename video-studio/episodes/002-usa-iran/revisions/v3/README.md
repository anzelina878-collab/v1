# Редакция 3: спокойное движение

Таймкоды, озвучка, последовательность сцен, фото, лицензии, широкие плашки и названия сохранены из редакции 2.

Все фото и статичные виды 3D неподвижны: один готовый кадр на весь план, без zoompan, сдвига или изменения масштаба. Информационные карточки по-прежнему появляются один раз, затем стоят неподвижно.

Скорость 3D-поворота постоянная: 360° за 24 секунды (15°/сек). Короткий план показывает только соответствующую часть оборота. В длинном плане — один оборот и удержание последнего ракурса. Из уже отрендеренной геометрии создаются промежуточные кадры с компенсацией движения до 30 fps; повторных циклов нет. Фото не выдаются за 3D.

Архивные видео сохраняют собственное движение камеры. Их искусственная стабилизация в эту правку не входит.

## Сборка

Из папки video-studio, установив FFmpeg, requirements.txt и numpy:

```sh
python episodes/002-usa-iran/render_revision_v3.py --preview
python episodes/002-usa-iran/render_revision_v3.py --work /tmp/arsenal-v3-cache --output /tmp/final_video_v3.mp4
python episodes/002-usa-iran/verify_revision_v3.py /tmp/final_video_v3.mp4 --compiled /tmp/arsenal-v3-cache --output /tmp/arsenal-v3-check
```

Параметр --reuse необязателен и применяется только для ранее проверенных неизменённых фрагментов. Без него сборка полностью самостоятельна. Для редактирования используются episode.v3.json, assets/manifest.v2.json и render_revision_v3.py, который наследует сохранённые рендеры v2/v1. Готовые 3D-источники, исходная геометрия, лицензии, фото, видео и исходная озвучка включены в ZIP.

Источники и лицензии: revisions/v2/SOURCES.md; метаданные в assets/manifest.v2.json и папках моделей. Технический отчёт и контрольные кадры: output/revision_v3. Непрерывный ручной просмотр всего фильма не заявляется; отдельно фиксируются автоматические проверки и просмотр последовательностей кадров.

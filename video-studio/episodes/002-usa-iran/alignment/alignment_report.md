# Привязка к предоставленной дорожке

Оригинальная длительность: 1397,448 с. Видео: 41924 кадра, 1397,4667 с при 30 fps. Голос не ускоряется и не переписывается.

Распознавание: faster-whisper small, CPU int8, язык uk, word_timestamps. Затем монотонное сопоставление исходного текста с распознанными словами (SequenceMatcher без autojunk) и интерполяция отдельных несовпадающих терминов по соседним совпавшим словам. Совпадение нормализованных слов: 90,0833%. Это показатель согласования, а не гарантия точности каждого термина.

Визуальные блоки назначены вручную в visual_map.py по смыслу конкретных абзацев; случайный автоматический подбор тематического стока не используется. ASR служит только для таймингов.

Таймкоды заголовков предоставленного текста отличаются от аудио и не использованы для растягивания речи. Итоговые главы находятся в chapters.uk.txt. Исходный текст и MP3 сохранены отдельно.

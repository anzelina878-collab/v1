# Контроль стыка настоящего 3D-оборота

Нативные банки содержат 720 кадров на 24 секунды. Сочетание input -ss с -stream_loop перезапускало чтение с точки input seek. Исправление только для 3D: читать цикл от нуля, затем trim=start=N,setpts=PTS-STARTPTS; скорость не меняется. Архивы не используют loop.

Проверка uk009-021 пересекает 24-секундную границу в четырёх точках: исходное расхождение 4.364 MAE уменьшилось до 0.10–0.14. Затем каждый 3D-план проверяется в трёх ракурсах независимо от рендера. См. output/qa/rotation-regression.json и native-3d-motion.json.

Один исходный исторический фрагмент HRT имел статический хвост. Он заменён движущимися кадрами водно-спасательной тренировки HRT 2022 года. Оригинальная пользовательская озвучка не изменялась.

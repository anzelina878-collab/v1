# ФБР: повне спорядження агентів і спецпідрозділів

Український випуск 009 для АРСЕНАЛ 360°. 1920×1080, 30 fps, 17:19.233. Оригінальна озвучка без зміни темпу.

119 сцен: офіційні архіви, реальні предметні фотографії, нативні 3D-банки з обертом за 24 секунди та короткі заголовки розділів. Фото й інформаційні слайди після появи зафіксовані. Архіви не зациклюються, не сповільнюються й не заморожуються.

## Повторний рендер з переносного ZIP

Розпакуйте архів. Потрібні Python, FFmpeg, numpy та Pillow з RAQM. Встановіть залежності з video-studio/requirements.txt. Запускайте з розпакованої папки video-studio:

```bash
python episodes/009-fbi-full-gear/render_episode.py --work /tmp/fbi-render --output final_video_v1.mp4
```

Пілот:

```bash
python episodes/009-fbi-full-gear/render_episode.py --work /tmp/fbi-pilot --pilot 90 --output pilot90.mp4
```

Перевірка:

```bash
python episodes/009-fbi-full-gear/check_episode.py --video final_video_v1.mp4 --work /tmp/fbi-render
```

episode.json містить незмінні покадрові межі, assets/manifest.json — фактичні джерела, chapters.uk.txt — розділи. Для нового відео створюється окремий випуск і нова розмітка озвучки; поточний не перезаписується.

3D-персонаж є умовною ілюстрацією. Готові рендер-банки включені; сирі Mixamo-модель і похідні текстури виключені згідно з ліцензійними умовами. Оригінальні носії цифрових доказів і CC0-карабін мають доступні геометричні джерела. Див. SOURCES.md.

## Межі перевірки

Повне декодування, кореляція звуку, контроль заголовків і закінчень рухомих сцен перевіряються окремо від вибіркового перегляду кадрів. Безперервний людський перегляд і прослуховування всього фільму не заявляється. Остаточні результати — output/qa і quality_report.md.

Соединённые Штаты Америки против Ирана. Отдельная адаптация утверждённого второго выпуска: 23:52.30, 1920×1080, 30 кадров/с. Оригинальная пользовательская озвучка.

final_video_hi_v1.mp4 — полный фильм. project_source_hi_v1.zip — автономные исходники с используемым медиа, шрифтами, лицензиями и кодом. Видео не опубликовано на YouTube.

## Пересборка из ZIP

Нужны Python 3.10+, FFmpeg/ffprobe, Pillow с libraqm, NumPy. Шрифты включены. Распакуйте архив, затем из папки video-studio/episodes/002-united-states-of-america-iran-hi:

```sh
python check_episode.py
python render_episode.py --work /путь/к/новому/кэшу --output /путь/к/готовому.mp4
python check_episode.py --video /путь/к/готовому.mp4 --work /путь/к/новому/кэшу
```

Готовые 24-секундные банки вращения входят в архив. Для обычной пересборки не нужны Blender, OpenGL, Whisper или загрузка материалов из сети. Не направляйте кэш внутрь папок готовых оригиналов.

Для нового монтажа по другой записи сначала подготовьте новую папку выпуска, текст, озвучку и смысловое соответствие. align_audio.py и refine_chapter_cues.py документируют применённое выравнивание; для повторного распознавания нужны отдельные faster-whisper и модель. Затем build_episode.py создаёт покадровый план по сохранённому выравниванию. Не заменяйте только аудиофайл без обновления плана: длительности и заголовки привязаны к текущей записи.

## Монтаж

181 сцена. Документальные видео идут с обычной скоростью; хвосты не замораживаются и не зацикливаются. Все выбранные участки помещаются в доступный исходный видеоматериал. Фото статичны; плашки появляются один раз и остаются неподвижными. Настоящие трёхмерные модели вращаются за 24 секунды на оборот, 720 непосредственно отрендеренных положений, без интерполяции фотографии. Два грубых макета заменены реальными вырезанными фото. Небольшие модели авианосца/подлодки подписаны как 3D-схемы; это не инженерные CAD-модели.

Десять заголовков разделов полностью появляются до звуковой точки входа: девять произнесённых названий и заключение у первой фразы итога. Таймкоды — chapters.hi.txt. Полный текст каждой сцены и её источник — episode.json, assets/manifest.json и assets/rights-manifest.json. Оригинальные материалы и лицензии — assets/library. Цвета, размеры плашек, логика появления — render_episode.py; общие примитивы — video-studio/studio.

# АРСЕНАЛ 360° — Ізраїль проти Ірану

Редагований візуальний проєкт випуску 005. Український сценарій та голос користувача збережені. Таймкоди визначаються за озвучкою, не за приблизними заголовками сценарію.

## Відтворення

Потрібні Python 3.11+, FFmpeg/FFprobe. Із ZIP розпакуйте всю папку `video-studio`, збережіть її структуру. Встановіть `pip install -r episodes/005-israel-iran/requirements-visual.txt`. Із папки `episodes/005-israel-iran`:

```sh
python build_episode.py
python render_episode.py --preview --work /tmp/arsenal-005/render
python render_episode.py --pilot 90 --work /tmp/arsenal-005/render --output output/pilot.mp4
python render_episode.py --work /tmp/arsenal-005/render --output output/final_video_v1.mp4
python verify_episode.py output/final_video_v1.mp4 --compiled /tmp/arsenal-005/render --output output/qa
python verify_motion.py /tmp/arsenal-005/render output/qa/motion-verification.json
```

Готові 3D-банки включено. Геометрія, текстури та ліцензії лежать у `assets/models`. Вони показують зовнішній вигляд родини техніки, не перевіряють її тактико-технічні характеристики. Для повторного розрахунку: додатково `numpy`, `numba`, потім `tools/render_model_banks.py`. Для M4 використовується `M4A1_Base_Color.png` замість `textures.npz`.

Карти — справжня тривимірна сітка висот із текстурою Natural Earth. Камера безперервно змінює ракурс; карти не заморожуються через 1,2 секунди. Висоти перебільшені у 8 разів для наочності. Проліт не є реконструкцією конкретного удару. Джерела висот та всі атрибуції збережені в `assets/maps`. Для регенерації банків потрібні `numpy`, `numba`:

```sh
python tools/map_banks.py --kind region --duration 24
python tools/map_banks.py --kind navy --duration 18
```

Фото нерухомі. Інформаційні картки з'являються один раз та утримуються. Техніка повільно обертається: 360° за 24 секунди, 30 кадрів/с; короткий план показує лише частину оберту. Архівні інтервали не повторюються й не зациклюються. Повернення до того самого джерела — більш ніж через 60 секунд після попереднього використання.

## Адаптація наступного випуску

Створіть нову папку випуску; попередню не змінюйте. Замініть лише новий сценарій і голос у новому проєкті. Розбийте сценарій на нумеровані абзаци `inputs/paragraphs.json`. Встановіть додаткові залежності з `requirements-preparation.txt`, виконайте `python tools/transcribe_audio.py --language uk`, збережіть `alignment/transcript.jsonl` та запустіть `align_audio.py`. Назва моделі завантажує відкриту ASR-модель за потреби; для локальної наявної моделі використовуйте `--model /path/to/model`. Це лише розпізнавання для монтажних міток, не новий голос. У `visual_map.py` виберіть матеріал за конкретною фразою; у `assets/manifest.json` запишіть джерело, ліцензію, авторство та доступні інтервали. Оновіть початкові сцени, правила розбиття, прапори, країни та обмеження інтервалів у `build_episode.py`; не переносіть ізраїльські/іранські предмети до іншої теми автоматично. Перевірте storyboard і 90-секундний пілот, потім експортуйте повний ролик.

`SOURCES.md` містить повні атрибуції. Підпис «родина/тип» відрізняє приклад платформи від конкретної національної модифікації. Випробування та архіви не видаються за кадри одного сучасного бою. Візуальний монтаж не є повним незалежним фактчеком усіх висновків наданого сценарію.

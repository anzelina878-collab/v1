# Незмінні матеріали користувача

- `inputs/script.uk.txt` — оригінальний сценарій Польща / Німеччина.
- `audio/voice.mp3` — оригінальна озвучка, 1288.128 секунди.
- `inputs/paragraphs.json` — розбиття тексту для монтажу.
- `alignment/transcript.jsonl` — допоміжне розпізнавання; не заміна голосу чи сценарію.
- `alignment/paragraphs.json`, `alignment/word_anchors.json` — часові прив'язки. Часові підказки в сценарії замінено фактичними межами озвучки.

Нові голоси не синтезувалися; темп і слова не змінювалися. Фінальна звукова доріжка перекодована в AAC для MP4.

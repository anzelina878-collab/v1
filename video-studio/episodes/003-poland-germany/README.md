# АРСЕНАЛ 360° — випуск 003: Польща / Німеччина

Фінальний монтаж: 1920×1080, 30 кадрів/с, 21:28.133. Оригінальні українські текст і голос збережено. Реальні фото, ліцензовані архівні відео, географічні карти та справжні оберти 3D-геометрії.

## Запуск з повного ZIP-проєкту

Потрібні Python 3.10+, FFmpeg/FFprobe та `pip install Pillow numpy`.

Із каталогу `video-studio`:

```bash
python episodes/003-poland-germany/render_episode.py --preview
python episodes/003-poland-germany/render_episode.py --pilot 90 --output episodes/003-poland-germany/output/pilot.mp4
python episodes/003-poland-germany/render_episode.py
python episodes/003-poland-germany/verify_episode.py episodes/003-poland-germany/output/final_video_v1.mp4 --compiled episodes/003-poland-germany/work
```

Git зберігає код і план; повний ZIP містить також голос, усі використані фото, відео, моделі, їх вихідні файли та ліцензії. Фінальне MP4 завантажується окремо. Великі матеріали не дублюються в звичайних Git-файлах.

## Налаштування наступного відео

Створіть новий каталог випуску; не змінюйте попередні. Додайте незмінений сценарій та озвучку. Після розпізнавання з часовими мітками `align_audio.py` зіставляє абзаци з голосом. В `visual_map.py` задаються конкретні предмети/кадри за абзацами; `build_episode.py` створює точний `episode.json`. Поточні абзаци та матеріали не можна автоматично переносити на іншу тему: відповідність зображення словам і ліцензія перевіряються окремо.

`episode.json` незалежно описує кожний план: час, тип, предмет, країну, підпис, джерельний інтервал. `assets/manifest.json` описує бібліотеку матеріалів. Рендерер підтримує `map`, `photo`, `archive`, `turntable`, `compare`, `graphic`, `section`, `question`, `outro`, `ident`. Для нових країн додайте векторні прапори й відповідну географію.

Фото нерухомі. Картки з'являються один раз за 1.2 с і завмирають. 3D: 360° за 24 с, короткі плани показують лише відповідну частину повороту; камера зафіксована. Моделі зі словом `illustrative` — оригінальні схематичні ілюстрації зовнішнього вигляду, позначені в кадрі; вони не є точними інженерними копіями. Реальні фото типу/родини не засвідчують поставку конкретної модифікації в конкретну країну.

## 3D

Попередньо розраховані 30 fps банки включені. Для повторного розрахунку з `mesh.npz` і `textures.npz` установіть також `numba`, потім:

```bash
python episodes/003-poland-germany/tools/render_model_banks.py
```

Нативні схематичні вихідники `.blend` та скрипти Blender входять до пакета. FlightGear `.ac`, текстури, ліцензії GPL і вихідна геометрія також включені. Відповідні ліцензії стосуються цих матеріалів; див. `SOURCES.md`, `assets/models/*/source.json` і локальні COPYING/LICENSE.

## Перевірка

Див. `output/verification.json`: повне декодування, кількість кадрів, синхронізація голосу, паузи між повторними джерелами, нерухомість карток і фотографій та темп 3D. Контрольні аркуші перевіряються візуально. Це не твердження про суцільний людський перегляд зі звуком.

Кеш сцен та цільовий MP4 мають файлове блокування у Linux/macOS, щоб паралельні процеси не писали в один фрагмент одночасно. У Windows запускайте одну збірку в один робочий каталог.

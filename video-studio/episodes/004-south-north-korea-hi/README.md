# ARSENAL 360 / शस्त्र 360 — South Korea / North Korea, Hindi edition

Отдельная хинди-версия утверждённого украинского выпуска 004. 16:42.333, 1920×1080, 30 кадров/с, 162 сцены. Пользовательские текст и озвучка сохранены без изменений. Украинский фильм и прошлые версии не перезаписывались.

## Пересборка из source ZIP

Нужны Python 3.10+, FFmpeg/ffprobe, NumPy и Pillow с libraqm/HarfBuzz. Из папки video-studio/episodes/004-south-north-korea-hi:

```sh
pip install -r requirements.txt
python check_episode.py
python render_episode.py --work /путь/к/новому/кэшу --output /путь/к/final_video_hi_v1.mp4
python check_episode.py --video /путь/к/final_video_hi_v1.mp4 --work /путь/к/новому/кэшу
```

Архив содержит действительный медиа-контент, шрифты с лицензиями и готовые банки вращения моделей. Для обычной пересборки не нужны Whisper, Blender, OpenGL и сетевое скачивание. Git хранит код, план и отчёты; полное медиа — в ZIP.

## Принятые решения

Сохранён визуальный порядок украинского фильма: реальные фото и вырезанные объекты, архивы, карты Корей, детальные модели F-16/Apache/Black Hawk. Фото неподвижны. У карточек один вход и удержание. 3D: 720 исходных геометрических поз на 24 секунды; без ускоренного полного оборота или деформации фотографии. Архивы идут с обычной скоростью; их концы не замораживаются, кадры не интерполируются, видео не зацикливается. При нехватке исходной длины код выбирает подходящий отдельный фото-план.

Диктор не читает письменные заголовки. Одиннадцать коротких названий разделов привязаны к произнесённым названиям тем соответствующих блоков. На заставках нет «F-35 против MiG-29» и подобных длинных названий. Русские пояснения в документе не попадают в кадр. Новые заставки ARSENAL 360 / शस्त्र 360 нарисованы кодом; старый видеобанк с кириллическим названием исключён из активной библиотеки.

Кириллица отсутствует в отображаемых подписях, картах и авторских строках. Имена авторов, для которых нужен другой алфавит, транслитерированы только на экране; оригиналы сохранены в реестрах. Исходные надписи реальной архивной съёмки и маркировка техники не выдаются за новые титры канала.

## Новый голос / следующий выпуск

Сохраните новую папку, неизменённый текст и голос. Нельзя просто заменить MP3: требуется новое выравнивание и смысловое соответствие абзацев. align_audio.py и refine_chapter_cues.py документируют применённое выравнивание, включая проверку по вероятностям; для их повторного запуска отдельно нужны faster-whisper и путь к локальной модели. build_episode.py пересобирает план по сохранённым временам; translations.py содержит проверяемый словарь, неизвестная кириллица вызывает ошибку. render_episode.py — текущие размеры, шрифты и анимации, tools/maps.py — подписанные географические карты.

## Проверка и источники

Итоговые отчёты — output/qa. Полный декод, сравнение звука, проверки конца вставок, просмотр раскадровок и отдельных кадров учитываются отдельно. Непрерывный человеческий просмотр и прослушивание всего фильма не заявляются. Это визуальная адаптация готовой речи, а не новый независимый фактчек всех её утверждений. Реальные фото типов/семейств не выдаются за конкретную технику северокорейской армии; необходимые пояснения переведены.

SOURCES.md и assets/rights-manifest.json содержат происхождение. Включены public domain, CC BY/CC BY-SA и KOGL Type 1; вся компиляция не является public domain. Модели, геометрия, текстуры и исходные лицензии находятся в assets/library/models. На YouTube ничего не опубликовано.

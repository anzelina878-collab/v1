# АРСЕНАЛ 360° — випуск 004: Південна Корея / КНДР

Готовий монтаж: 1920×1080, 30 кадрів/с, 16:53.400. Сценарій та оригінальна українська озвучка надані користувачем і збережені. Інформаційні плашки мають один вступ, потім завмирають; фотографії не рухаються. Замість спрощених зелених 3D-танків використано реальні фото з перевіреним відділенням фону або цілі фотографії. Детальні 3D-моделі F-16, Apache та Black Hawk обертаються з темпом 360° за 24 с. Об'ємний глобус показує географічне положення двох Корей, регіональні карти — країни та столиці.

## Завантаження та запуск

Повний ZIP містить код, сценарій, оригінальний MP3, використані медіа, карти, прапори, 3D-геометрію, ліцензії й контрольні звіти. Git містить код та план; великі матеріали доступні в ZIP. Фінальне MP4 завантажується окремо.

Потрібні Python 3.10+, FFmpeg / FFprobe та `pip install Pillow numpy`. Із каталогу `video-studio`:

```bash
python episodes/004-south-north-korea/render_episode.py --preview
python episodes/004-south-north-korea/render_episode.py --pilot 90 --output episodes/004-south-north-korea/output/pilot.mp4
python episodes/004-south-north-korea/render_episode.py
python episodes/004-south-north-korea/verify_episode.py episodes/004-south-north-korea/output/final_video_v1.mp4 --compiled episodes/004-south-north-korea/work
python episodes/004-south-north-korea/verify_motion.py episodes/004-south-north-korea/work episodes/004-south-north-korea/output/motion-verification.json
```

У Linux/macOS файлові блокування захищають кеш сцен від одночасного запису. У Windows запускайте одну збірку в один робочий каталог. Не змінюйте сценарій, медіа чи код, поки рендер працює.

## Адаптація наступного випуску

Створіть нову папку випуску, збережіть незмінені текст і голос. Розпізнавання з часовими мітками є допоміжним; `align_audio.py` зіставляє його зі сценарієм. У `visual_map.py` вручну задається точний предмет та роль кожного зображення за абзацами. `build_episode.py` складає неперервний план `episode.json` за фактичним голосом. Не переносіть предмети чи абзаци цього випуску на іншу тему без нового підбору.

`assets/manifest.json` — бібліотека матеріалів і джерел. `episode.json` — час кожного плану, підписи, країна, тип сцени й джерельний інтервал. Підтримуються photo, archive, turntable, map, compare, graphic, section, question, outro, ident. Карти редагуються в `tools/maps.py`, підписи та анімації — в `render_episode.py`.

Для нових вирізаних фото є `tools/prepare_cutout.py` (додатково rembg та onnxruntime). Маски перевіряються візуально: неправильну маску відхиляють і залишають ціле фото. Нову геометрію техніки не домальовують. 3D-банки вже включені; для їх повторного розрахунку з вихідної геометрії встановіть numba та запустіть `tools/render_model_banks.py` з папки випуску.

## Джерела та перевірка

`SOURCES.md` містить повні атрибуції й умови. Прапор показує сторону порівняння; фото з позначенням «тип/родина» не видається за конкретний борт або підрозділ цієї країни. Американські RQ-4 та MQ-9 чітко підписані як приклади для порівняння форми, а не як фотографії Saetbyol. Старі архіви датовані там, де це важливо. Схожість зовнішнього вигляду не є перевіркою характеристик.

Голос не переписували і не прискорювали. Це візуальний монтаж наданого сценарію, а не повний незалежний фактчек усіх його тверджень. Декодування, синхронізація, нерухомість фото/карток та темп 3D перевіряються окремо від перегляду контрольних кадрів. Суцільний людський перегляд зі звуком не заявляється.

# Как продолжаем работу

Этот проект — постоянная база для создания видеоряда следующих выпусков.

## Что отправлять в чат

> Новый выпуск для video-studio. Текст и готовая озвучка приложены.
> Создай под них видеоряд в текущем стиле.
> Тема: ...
> Обязательные изображения/вставки: ... (если есть).
> Формат: 1920×1080, YouTube (если не нужен другой).

Можно просто прислать текст и аудио и указать, что это новый выпуск.
Текст нужен для понимания визуальных задач; движок не выводит весь текст
автоматически на экран. Сценарий и голос здесь не создаём.

## Что готовим для каждого выпуска

- отдельную папку `episodes/<название>/`;
- набор изображений и клипов;
- `episode.json` с содержанием и таймингами;
- раскадровку для просмотра;
- готовый MP4 с предоставленным голосом, если он подключён;
- правки сцен без изменения других выпусков.

## Где менять разные вещи

| Задача | Файл |
|---|---|
| Заменить предметы, подписи, порядок, длительность | `episodes/.../episode.json` |
| Подключить голос | поле `audio` в том же JSON |
| Заменить изображения | папка `episodes/.../assets/` |
| Изменить цвета одного выпуска | поле `theme` в его JSON |
| Изменить общую геометрию карточки для серии | `studio/visuals.py` |
| Добавить совершенно новый тип сцены | `studio/visuals.py` и проверка в `studio/project.py` |

Сначала смотрим `output/storyboard.jpg` и `output/demo.mp4`.
Полные команды — в README.md, описание полей — в FORMAT.md.

Демонстрация показывает работу кода. Это не утверждённый окончательный
дизайн канала: плотность графики, палитру, шрифты и темп можно изменить.
